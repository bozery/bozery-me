# Website fonts

Coast WenKai is a renamed, WOFF2 subset version of LXGW WenKai Lite Regular. Coast Cormorant is a renamed Latin subset of Cormorant Garamond Medium Italic. Glyph outlines are unchanged. Original SIL OFL licenses are included.

Sources:
- https://github.com/lxgw/LxgwWenKai-Lite
- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

WenKai includes the source character coverage, split by Unicode range. The first file covers the current site; other files load on demand for new text. All files are self-hosted with font-display:swap.
